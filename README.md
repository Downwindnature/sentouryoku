# 戰力名單

記錄每個人的戰力、筆記與評分方式的網站。網頁可以放在 **GitHub Pages**（或 Firebase Hosting），資料存在 **Firebase Realtime Database**，用免費的 Spark 方案就能跑。

**不用登入**：任何拿到網址的人都能看，也都能編輯。每個分頁都有自己的「編輯者」：新增分頁時填寫，左上角會顯示目前這個分頁的編輯者。

---

## 功能

- **編輯者**：新增分頁時，在「新增」按鈕旁邊填寫。左上角只顯示目前分頁的編輯者（不能在那裡改），切換分頁會跟著換；要修改的話，點分頁 →「修改名稱與編輯者」
- **底部分頁籤**（像 Excel）：按最左邊的「＋」新增分頁。點一下其他分頁會切換過去；點**目前所在的分頁**（電腦也可以按右鍵、手機可以長按）會跳出選單：
  - **下載備份檔案**：先問「是／否」，按「是」下載 JSON 備份
  - **修改名稱與編輯者**
  - **刪除**：分頁裡還有資料時，會提醒你必須先把那幾筆全部刪除；清空之後才會問「是否刪除該分頁」
- **名單**：一頁最多 5 筆，可以用名字搜尋、按「清除」回到全部，也可以排序（新增順序、最近更新、戰力高→低、戰力低→高、名字）
- **換頁**：下方有「最上頁／上一頁／下一頁／最下頁」；中間的頁數可以直接輸入，按 Enter 就跳到那一頁（輸入超過總頁數會跳到最後一頁）
- **置頂**：每筆名單都有「置頂」按鈕。按下後會變成「已置頂」，那筆名單會固定在最上面，並跳出提示「再按一次就可以取消置頂」。置頂不算修改內容，不會改到上次更新時間；同時有好幾筆置頂時，最後置頂的排最上面
- **新增表單／編輯**：頭像、戰力、名字、內容
  - **頭像**可以用圖片、GIF 或 MP4。GIF 和 MP4 在名單上會動，MP4 一律靜音、自動重複播放；一般圖片會自動裁成正方形。不設定就顯示預設頭像
  - **套用**：存檔但不關視窗　**確定**：存檔並關閉　**取消／×**：不存檔關閉（有改過會先確認）
  - 新增名單沒有「上次更新時間」和「翻閱過往紀錄」，存檔後才會出現
  - 時間格式：`2026/11/7 23:43:51`
- **內容區（像 Word）**：直接打字，可以改字級、粗體、斜體、底線、刪除線、文字顏色、螢光標記、對齊、清單
  - 插入**圖片、GIF、MP4 影片**，也可以直接貼上截圖或把檔案拖進來
  - 點一下圖片：選「靠左繞圖／置中／靠右繞圖／跟文字同一行」，用 − ＋ 或拖右下角的藍點調整大小
  - **移動圖片**：電腦直接用滑鼠按住圖片拖；手機**長按圖片約半秒**再拖（也可以按住工具列的 ✥ 拖）。拖的時候圖片會直接跟著移過去，看到的就是放開後的樣子：
    - 拖到左邊／中間／右邊，會自動變成靠左繞圖／置中／靠右繞圖
    - 拖到文字中間就插在那一行；拖到內容最下面再往下，會自動補空白行，所以空白的地方也放得上去
    - 拖到編輯區上下邊緣會自動捲動；拖到一半按 Esc 可以取消
  - 手機上：工具列可以左右滑（圖片、影片、手繪放在最前面）；點圖片時鍵盤會先收起來，方便調整
  - **手繪**：畫筆、螢光筆、直線、箭頭、方框、圓形、橡皮擦；也可以點圖片後選「手繪標註」直接在圖片上畫
  - 手機上太寬的繞圖會自動改成整排顯示，比較好讀
- **翻閱過往紀錄**：每次存檔，舊版本都會自動保留。可以看「當時紀錄」的時間、頁數、上一頁／下一頁，按「返回編輯」回去；編輯中也可以「還原此版本」
- **戰力評分方式**：每個分頁各有一份，一樣可以打字、放圖片影片、手繪
- 電腦、手機都能用；會跟著系統自動切換深色模式

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本體 |
| `css/style.css` | 外觀 |
| `img/default-avatar.jpg` | 預設頭像（想換的話，用同樣檔名的圖片覆蓋即可） |
| `js/config.js` | **唯一需要改的檔案**：Firebase 設定、每頁筆數、檔案大小上限等 |
| `js/*.js` | 程式（不用改） |
| `database.rules.json` | 資料庫安全規則，要貼到 Firebase |
| `firebase.json`、`.firebaserc` | 只有用 Firebase Hosting 部署時才用得到 |
| `.nojekyll` | 給 GitHub Pages 用，留著就好 |

## 一、先在電腦上看看

`js/config.js` 的 `apiKey` 沒填的時候，網站會用**示範模式**執行：資料只存在這台電腦的瀏覽器裡。填了之後就會連到 Firebase。

這個網站用了 JavaScript 模組，**不能直接雙擊 `index.html` 開啟**，要用本機伺服器：

- VS Code 安裝「Live Server」擴充功能 → 在 `index.html` 按右鍵 → **Open with Live Server**
- 或在資料夾裡執行 `npx serve`（需要先裝 Node.js）

也可以直接照第三步上傳到 GitHub Pages 看。

---

## 二、設定 Firebase（大約 5 分鐘）

> 這份專案的 `js/config.js` 已經填好 **sentouryoku** 專案的設定，第 3 步可以跳過。

1. **建構 → Realtime Database** → 建立資料庫 → 位置選 **新加坡（asia-southeast1）**。
2. **建構 → Authentication** → **開始使用** → **登入方式** → 新增供應商選「**匿名**」→ 啟用 → 儲存。
   使用者不會看到任何登入畫面；這只是讓資料庫知道寫入是從你的網站來的，擋掉直接對資料庫亂寫的程式。
3. 齒輪 **專案設定** → **一般** → 你的應用程式 → 網頁應用程式的 `firebaseConfig`，把值貼進 `js/config.js`。**一定要有 `databaseURL`**。
4. 回到 **Realtime Database → 規則**，把 `database.rules.json` 的內容整個貼上（取代原本的）→ **發布**。

> `apiKey` 會出現在公開的網頁上是正常的，它不是密碼。

---

## 三、上傳到 GitHub Pages

1. 在 GitHub 建立新的 repository（Public）。
2. 把這個資料夾**裡面的所有檔案**上傳（`index.html` 要在最外層，`.nojekyll` 也一起上傳）。
3. repository 的 **Settings → Pages** → Source 選 **Deploy from a branch** → Branch 選 `main`、資料夾選 `/ (root)` → **Save**。
4. 等 1～2 分鐘，網址會是 `https://你的帳號.github.io/repository名稱/`。

之後只要改了檔案，重新上傳覆蓋就好。每次更新請把 `index.html` 和 `js`、`css` 資料夾一起上傳（`index.html` 裡有版本號，換了版本號瀏覽器就會抓新的程式）。如果畫面看起來還是舊的，電腦按 **Ctrl+F5** 強制重新整理。

## （選擇）用 Firebase Hosting 部署

需要 Node.js（`.firebaserc` 已經填好專案 ID）：

```bash
npm install -g firebase-tools
firebase login
firebase deploy        # 同時上傳網頁和資料庫規則
```

網址會是 `https://sentouryoku.web.app`。

## 四、開始使用

1. 打開網站 → 按左下角「**＋**」→ 填「分頁名稱」和「**編輯者**」→ 新增。
2. 按上方「**新增表單**」新增名單。
3. 把網址分享給大家，就能一起看、一起編輯。

> **提醒**：任何拿到網址的人都能新增、修改、刪除。修改過的內容會留在「過往紀錄」裡可以還原，但「刪除名單」是永久的，記得偶爾從分頁選單「下載備份檔案」。

## 容量與限制（Firebase 免費 Spark 方案）

- Cloud Storage for Firebase 從 2026 年 2 月 3 日起一律需要付費的 Blaze 方案，所以這個網站把圖片、GIF、影片都直接存在 Realtime Database，**免費方案就能用**。
- Realtime Database 免費額度：儲存 **1 GB**、每月下載 **10 GB**。
- 為了省空間和流量：
  - 圖片會自動縮小壓縮（長邊 1600 像素）
  - GIF 上限 8 MB、影片上限 20 MB（`js/config.js` 可以改）
  - 名單卡片只載入縮圖；影片要按「播放影片」才會下載
- 每筆名單保留最近 **50 筆**過往紀錄（`js/config.js` 的 `historyLimit`，0 代表不限制）。
- GIF／MP4 頭像上限 **5 MB**（`js/config.js` 的 `avatarMaxMB`）。動態頭像每次有人打開那一頁都會下載，檔案越小越省流量。

## 備份與還原

- **備份**：點目前的分頁 → 下載備份檔案 → 是。會下載一個 JSON 檔，裡面有這個分頁的所有名單、過往紀錄、戰力評分方式和圖片影片。
- **還原**：按「＋」→「從備份檔匯入…」→ 選 JSON 檔。會建立成一個新的分頁，不會覆蓋現有資料。

## 常見問題

- **存檔時跳出「編輯功能還沒開啟」**：到 Authentication → 登入方式，啟用「匿名」。
- **存檔時跳出「資料庫拒絕寫入」**：到 Realtime Database → 規則，重新貼上 `database.rules.json` 的內容並按「發布」。
- **畫面顯示「無法讀取資料」**：同上，資料庫規則還沒換成新的。
- **網站顯示「無法載入 Firebase」**：確認網路正常，並檢查 `js/config.js` 是否完整（特別是 `databaseURL`）。
- **想換預設頭像**：把新圖片命名成 `default-avatar.jpg`，覆蓋 `img` 資料夾裡的同名檔案。
