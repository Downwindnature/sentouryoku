# 戰力名單記錄每個人的戰力、筆記與評分方式的網站。網頁可以放在 **GitHub Pages**（或 Firebase Hosting），資料存在 **Firebase Realtime Database**，用免費的 Spark 方案就能跑。---## 功能- **底部分頁籤**（像 Excel）：按最左邊的「＋」新增分頁。點一下其他分頁會切換過去；點**目前所在的分頁**（電腦也可以按右鍵、手機可以長按）會跳出選單：  - **下載備份檔案**：先問「是／否」，按「是」下載 JSON 備份  - **重新命名**  - **刪除**：分頁裡還有資料時會提醒你必須先把那幾筆全部刪除；清空之後才會問「是否刪除該分頁」- **名單**：一頁最多 5 筆，上一頁／下一頁換頁，可以用名字搜尋、按「清除」回到全部，也可以排序（新增順序、最近更新、戰力高→低、戰力低→高、名字）- **置頂**：每筆名單都有「置頂」按鈕。按下後會變成「已置頂」，那筆名單會固定在最上面，並跳出提示「再按一次就可以取消置頂」。置頂不算修改內容，所以不會改到上次更新時間；同時有好幾筆置頂時，最後置頂的排最上面- **新增表單／編輯**：頭像（不設定就顯示預設頭像）、戰力、名字、內容  - **套用**：存檔但不關視窗　**確定**：存檔並關閉　**取消／×**：不存檔關閉（有改過會先確認）  - 新增名單沒有「上次更新時間」和「翻閱過往紀錄」，存檔後才會出現  - 時間格式：`2026/11/7 23:43:51`- **內容區（像 Word）**：直接打字，可以改字級、粗體、斜體、底線、刪除線、文字顏色、螢光筆、對齊、清單  - 插入**圖片、GIF、MP4 影片**，也可以直接貼上截圖或把檔案拖進來  - 點一下圖片：選「靠左繞圖／置中／靠右繞圖／跟文字同一行」，用 − ＋ 或拖右下角的藍點調整大小，按住 ✥ 拖到想放的位置  - **手繪**：畫筆、螢光筆、直線、箭頭、方框、圓形、橡皮擦；也可以點圖片後選「手繪標註」直接在圖片上畫  - 手機上太寬的繞圖會自動改成整排顯示，比較好讀- **翻閱過往紀錄**：每次存檔，舊版本都會自動保留。可以看「當時紀錄」的時間、頁數、上一頁／下一頁，按「返回編輯」回去；編輯中也可以「還原此版本」- **戰力評分方式**：每個分頁各有一份，一樣可以打字、放圖片影片、手繪- **帳號**：Google 登入。第一個登入的人可以設為「擁有者」，擁有者可以加入其他編輯者、決定要不要公開給沒登入的人看- 電腦、手機都能用；會跟著系統自動切換深色模式---## 檔案說明| 檔案 | 用途 ||---|---|| `index.html` | 網頁本體 || `css/style.css` | 外觀 || `img/default-avatar.jpg` | 預設頭像（想換的話，用同樣檔名的圖片覆蓋即可） || `js/config.js` | **唯一需要改的檔案**：Firebase 設定、每頁筆數、檔案大小上限等 || `js/*.js` | 程式（不用改） || `database.rules.json` | 資料庫安全規則，要貼到 Firebase || `firebase.json`、`.firebaserc` | 只有用 Firebase Hosting 部署時才用得到 || `.nojekyll` | 給 GitHub Pages 用，留著就好 |---## 一、先在電腦上看看（示範模式）`js/config.js` 的 `apiKey` 還沒填的時候，網站會用**示範模式**執行：資料只存在這台電腦的瀏覽器裡，不會上傳。這個網站用了 JavaScript 模組，**不能直接雙擊 `index.html` 開啟**，要用本機伺服器：- VS Code 安裝「Live Server」擴充功能 → 在 `index.html` 按右鍵 → **Open with Live Server**- 或在資料夾裡執行 `npx serve`（需要先裝 Node.js）也可以直接照第三步上傳到 GitHub Pages 看。---## 二、設定 Firebase（大約 10 分鐘）1. 到 [Firebase 主控台](https://console.firebase.google.com/) 建立專案（Google Analytics 可以關掉）。2. 左側 **建構 → Realtime Database** → **建立資料庫** → 位置選 **新加坡（asia-southeast1）** → 選「**以鎖定模式啟動**」。3. 左側 **建構 → Authentication** → **開始使用** → **登入方式** → 新增供應商選 **Google** → 啟用 → 儲存。4. Authentication → **設定** → **已授權網域** → **新增網域**，加入你的網站網域：   - GitHub Pages：`你的帳號.github.io`   - 本機測試：`localhost` 預設已經有了5. 左上角齒輪 **專案設定** → **一般** → 最下面「你的應用程式」按 **`</>`** 新增網頁應用程式 → 註冊後會看到一段 `firebaseConfig`，把裡面每個值貼進 `js/config.js` 對應的位置。   - **一定要有 `databaseURL`**（長得像 `https://你的專案-default-rtdb.asia-southeast1.firebasedatabase.app`）。如果那段設定裡沒有，到 Realtime Database 頁面上方複製網址貼上。6. 回到 **Realtime Database → 規則**，把 `database.rules.json` 的內容整個貼上（取代原本的）→ **發布**。> `apiKey` 會出現在公開的網頁上是正常的，它不是密碼。真正保護資料的是第 6 步的安全規則：只有擁有者和編輯者名單裡的帳號能寫入。---## 三、上傳到 GitHub Pages1. 在 GitHub 建立新的 repository（Public）。2. 把這個資料夾**裡面的所有檔案**上傳（`index.html` 要在最外層，`.nojekyll` 也一起上傳）。3. repository 的 **Settings → Pages** → Source 選 **Deploy from a branch** → Branch 選 `main`、資料夾選 `/ (root)` → **Save**。4. 等 1～2 分鐘，網址會是 `https://你的帳號.github.io/repository名稱/`。之後只要改了 `js/config.js` 或其他檔案，重新上傳覆蓋就好。---## （選擇）用 Firebase Hosting 部署如果想把網頁也放在 Firebase（需要 Node.js）：```bashnpm install -g firebase-toolsfirebase loginfirebase use --add     # 選你的專案（會自動改好 .firebaserc）firebase deploy        # 同時上傳網頁和資料庫規則```網址會是 `https://你的專案ID.web.app`，這個網域已經自動加在已授權網域裡。---## 四、第一次使用1. 打開網站 → 點左上角「**編輯者**」→ **使用 Google 登入**。2. 網站會問要不要把你設為「**擁有者**」→ 按「設為擁有者」。   **請部署好後自己先登入**，因為第一個按下的人就會成為擁有者。3. 按左下角「**＋**」新增第一個分頁，再按上方「**新增表單**」新增名單。4. 想讓朋友一起編輯：點「編輯者」→ 在「編輯者名單」輸入對方的 Google Email → 新增。對方登入後就能編輯。5. 不想讓沒登入的人看到：點「編輯者」→ 關掉「**公開檢視**」。之後只有擁有者和編輯者登入後才看得到。---## 容量與限制（Firebase 免費 Spark 方案）- Cloud Storage for Firebase 從 2026 年 2 月 3 日起一律需要付費的 Blaze 方案，所以這個網站把圖片、GIF、影片都直接存在 Realtime Database，**免費方案就能用**。- Realtime Database 免費額度：儲存 **1 GB**、每月下載 **10 GB**。- 為了省空間和流量：  - 圖片會自動縮小壓縮（長邊 1600 像素）  - GIF 上限 8 MB、影片上限 20 MB（`js/config.js` 可以改）  - 名單卡片只載入縮圖；影片要按「播放影片」才會下載- 每筆名單保留最近 **50 筆**過往紀錄（`js/config.js` 的 `historyLimit`，0 代表不限制）。---## 備份與還原- **備份**：點目前的分頁 → 下載備份檔案 → 是。會下載一個 JSON 檔，裡面有這個分頁的所有名單、過往紀錄、戰力評分方式和圖片影片。- **還原**：按「＋」→「從備份檔匯入…」→ 選 JSON 檔。會建立成一個新的分頁，不會覆蓋現有資料。---## 常見問題- **按登入出現「已授權網域」的錯誤**：到 Authentication → 設定 → 已授權網域，加入目前網址的網域。- **用 LINE、Facebook 等 App 打開網址無法登入**：Google 不允許在 App 內建瀏覽器登入，請改用 Chrome 或 Safari 打開。- **登入視窗沒跳出來**：瀏覽器擋了彈出式視窗，請允許這個網站開啟彈出式視窗。- **擁有者被別人搶先設定了／想換擁有者**：到 Firebase 主控台 → Realtime Database → 資料，刪掉最上層的 `owner`，再由正確的人登入設定。- **網站顯示「無法載入 Firebase」**：確認網路正常，並檢查 `js/config.js` 是否完整貼上（特別是 `databaseURL`）。
